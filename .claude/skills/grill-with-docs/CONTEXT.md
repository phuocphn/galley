# Small-Talk English Coach

A Claude skill that turns a short everyday topic into a mock small-talk conversation plus a coaching breakdown, saved as a note in the Obsidian vault so the learner builds a reviewable corpus over time. Aimed at casual coworker small talk (e.g. the daily walk to lunch), for a Vietnamese speaker of English.

## Language

**Topic**:
The short input the learner types to start a session — a news item, something about a person, an event, or anything they want to share.
_Avoid_: Context, seed, prompt, situation, subject.

**Session note**:
The single Markdown note produced per session and saved to the vault, containing the mock conversation and the full breakdown.
_Avoid_: Output, document, file, doc.

**Mock conversation**:
The generated example dialogue between the learner and a coworker, written in natural casual native register.
_Avoid_: Script, dialogue, example, sample.

**Cheat sheet**:
The 3–5 line at-a-glance block at the top of the note (headed "🍽️ Before lunch") — opener line, key phrases, exit line — pulled verbatim from the conversation for a last-second look before lunch.
_Avoid_: Summary, TL;DR, recap, takeaways.

**Breakdown**:
The coaching part of the note — everything that teaches from the mock conversation (Structure, Vocabulary, Natural phrasing, Common mistakes).
_Avoid_: Analysis, notes, explanation.

**Structure**:
The breakdown section that decodes how the conversation is built. Two sub-blocks: **Flow** (the move-by-move skeleton — opener → hook → reaction → follow-up → exit) and **Patterns** (reusable fill-in-the-blank sentence frames).
_Avoid_: Grammar, outline, format.

**Vocabulary**:
The breakdown section listing key words/phrases from the conversation. Each entry carries: Vietnamese gloss, IPA/pronunciation (with stress and final consonants), a natural example sentence, and a register tag (casual / neutral / slang).
_Avoid_: Words, terms, glossary.

**Natural phrasing**:
The breakdown section showing how a native would casually express something, typically contrasted against a stiff or textbook version.
_Avoid_: Idioms, expressions, fluency.

**Common mistakes**:
The breakdown section listing likely errors. Two labeled sub-blocks: **Interference errors** (mistakes Vietnamese speakers typically make — articles, plural -s, tense, prepositions, final consonants) and **Topic traps** (mistakes tied to this conversation's specific vocab/phrasing regardless of L1).
_Avoid_: Errors, corrections, pitfalls.
